# Lottie Previewer

Upload multiple Lottie animation JSON files and preview them in the browser with a simple carousel.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Usage

- **Choose files** or drag and drop one or more `.json` Lottie files onto the input panel.
- Use **arrow buttons**, **dot indicators**, or **← / →** keys to move between animations when more than one file is loaded.
- Click a file in the list to jump to that animation, or remove individual files with **×**.
- Click **Edit colors** on the preview panel to open the color editor (global swatches and per-layer controls). Use **Reset** to revert the current file, or **Download JSON** to save edits.
